## 从这里开始

打开 [目录式交互学习手册](interactive/投资新手知识地图.html)：左侧是逐层学习目录，右侧默认展开完整主题正文，按需提供参数试验、完整工具与本节笔记。支持上一节 / 下一节、标记已学、目录查找与个人总结。单文件可离线打开。

学习顺序为：**投资工作手册 → 投资基础 → 价值判断 → 企业研究 → 组合管理 → 跨代规划 → 信息来源与跟踪 → 我的总结与资料**，共 9 个入口、5 个完整知识章节，另增信息来源与跟踪方法，另保留书籍、原文与公开资料入口。完整目录见[学习路径](notes/08-学习目录与路径.md)。

“我的总结”以[框架草案](notes/09-我的投资总结.md)为起点，个人结论由用户填写。总结编辑区直接出现在该页顶部，可点击保存；每节还有独立的自动保存笔记区，不回写磁盘 Markdown。顶部固定提供“写本节笔记”“导出全部笔记”“我的总结与笔记”。可单节导出 Markdown，也可导出 / 导入含总结、章节笔记和学习进度的 JSON。导入合并章节笔记，同名章节以备份为准；总结和进度取自备份。跨浏览器或变更文件地址时，应使用导出的备份恢复。

## 交互文档维护

目录由 `interactive/curriculum.json` 指定学习层级和原文小节，`curriculum.html/css/js` 提供目录、进度、章节笔记和个人总结；`learning-lab.js` 按章节提供六项参数试验，同章可切换；组合章也可切换持仓、压力和研究卡，长期章保留购买力工具。旧工具源文件继续保留，页面不再挂载重复的练习。规划工具部分由 Markdown 笔记与 `interactive/planning-extension.html`、`planning-extension.css`、`planning-tools.js` 生成，避免手工复制后内容不一致。页面输出仍是无外部运行依赖的单个 HTML。

修改笔记后，在本目录执行：

```sh
node build_interactive.mjs /绝对路径/到/marked/lib/marked.esm.js
```

构建时需要已安装的 `marked`；日常打开 HTML 不需要 Node 或联网。新工具使用绝对百分点阈值、人为冲击、固定年末投入等简化假设；不是回测或最优配置。家庭应急金在组合外，组合现金只计算一次。

## 可控制的PDF阅读与批注（2026-10-28）

书籍章节已由原生iframe改为本地PDF.js画布阅读器，支持上一页/下一页、页序跳转、适宽缩放、框选高亮、选区文字批注、整页笔记、编辑删除与定位。PDF原件不改动。

- 推荐双击知识库根目录的 `启动阅读器.command`，或运行 `python3 serve_reader.py`。服务仅监听127.0.0.1:8765，自动打开书籍章节并读取原书。阅读时保留终端，Ctrl+C停止。端口被占用时先检查已有服务；可用`--port`明确指定其他端口。不同端口有独立浏览器存储，换端口或浏览器前先导出备份。
- 仍可双击HTML离线使用。浏览器禁止页面任意读取本地文件，因此需“选择本书PDF”；按SHA-256核对原件版本，选错不会套用批注。不会把PDF上传。刷新后文件权限不保留，需要重选；本页会话缓存最近一本，切换和返回可复用。
- 批注使用独立浏览器存储 `football-book-annotations-v1`，按书、SHA-256和PDF页序保存。JSON导出/导入可恢复继续编辑；按批注ID合并，同ID导入值优先，未列项目不删除。
- 顶部“导出全部笔记”已包含书籍批注；也可以在阅读器单独导出全部书籍批注JSON。旧备份仍可导入，不含批注字段时不清除现有批注。
- “导出本书批注PDF副本”将高亮和中文注释写成PDF批注对象，不覆盖原件。其他阅读器显示支持可能不同，继续在本库编辑请保留JSON。加密、损坏或不支持的PDF导出失败时会明确提示，不伪报成功。
- PDF.js 5.4.296与pdf-lib 1.17.1的源码和许可证在`interactive/vendor/`；JavaScript嵌入单文件HTML，辅助字体、CMap、WASM随vendor一起复制，无运行时CDN。新增脚本`serve_reader.py`与`启动阅读器.command`也应随手动交接复制。

`node tests/pdf-annotations.cjs`校验批注恢复、版本/坐标/页序校验、合并与打包资产一致性。浏览器实测真实原书翻页、缩放、画选区、中文批注、PDF/全量JSON导出、刷新恢复、手机与file模式；导出PDF另经解析确认存在Highlight和Text批注对象。

## 双击即读与自动续读（最新使用方式，2026-10-28）

直接打开`interactive/投资新手知识地图.html`或`interactive/index.html`即可选书阅读和批注，不再要求选择文件或启动终端。无网址片段时恢复上次章节；进入书籍章节恢复上次书籍、PDF页码、缩放和已保存批注。批注输入即自动保存，原保存按钮仍可使用；“结束编辑”只退出编辑，不撤回已保存内容。

为兼容file协议，`build_book_data.mjs`为18本原书生成`interactive/pdf-data/b01.js`至`b18.js`，运行时仅加载选中一本。数据是PDF字节的Base64本地副本，每次载入仍按原SHA-256核对，不绕过版本检查。不含上传服务、不需要联网，也不改变浏览器安全设置。新增数据约298 MiB，代价是磁盘多存一份；主HTML不嵌入整套PDF。`build_interactive.mjs`会增量调用此生成器，未提供PDF的接手工程可保留已交接的阅读数据。

手动交接时，`interactive/`必须包含整个`pdf-data/`；额外复制`build_book_data.mjs`。仅复制主HTML可保留界面、归纳和已嵌入JS，但不能自动读缺失的书籍数据。PDF原件未来重给后，可运行生成器补回阅读数据。独立打开原件与重新生成仍使用`raw/books/`。旧本机服务作为可选兼容方式保留，日常不需要。

进度与批注保存到同一浏览器的本地存储，不回写原PDF或自动同步其他设备。隐私模式、存储被禁用、清除浏览器数据或文件路径改变可能影响保留；保存失败会提示。导出全部笔记JSON包含章节笔记、批注、书籍页码和缩放，用于迁移与备份。

验证：`node tests/book-data.cjs`逐本核对阅读数据还原后的字节与原SHA-256。浏览器实测纯file模式自动加载、切书、自动保存文字、关闭页面及重启浏览器续读，全程无选文件、无服务器。

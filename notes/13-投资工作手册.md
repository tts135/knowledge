# 投资工作手册：先用这一份

整理日期：2026-10-21。此手册把本库知识、书籍笔记与资讯入口归纳成可重复使用的工作材料。适配用户提出的全球多资产、周期再平衡、机会现金与跨代账户框架；不是依据真实资产负债完成的个人适当性方案，也不承诺策略收益。具体比例、现金下限、产品选择与税务身份仍待填写。

所谓“有效资料”，在这里指能回答一个明确问题、有原始依据、口径可比较、能留下判断记录；不是资料越多越好，也不是任何指标都能准确预测市场。

## 1. 一页掌握整套框架

**先保家庭支付能力 → 再定长期目标与风险预算 → 研究实际资产 → 用资讯复核假设 → 在规则内调整 → 保留记录并定期复盘。**

| 层次 | 需要形成的判断 | 输出材料 |
|---|---|---|
| 家庭约束 | 什么钱不能冒险、何时需要、用什么币种？ | 资金与目标清单、投资政策 |
| 长期配置 | 哪些风险值得承担，各资产服务什么目的？ | 目标比例、上限与现金底线 |
| 信息与研究 | 什么新事实改变原先判断？ | 月度事实摘要、标的研究卡 |
| 执行 | 是否触发规则，能否承受，成本如何？ | 调整记录或不调整的理由 |
| 下一代 | 目标日期、购买力和接管安排是否仍适用？ | 独立目标账、年度检查 |

**默认工作顺序是目标与约束在前，宏观判断在后。** 用户关注的宏观周期可以帮助复核风险，但不应成为每天重写目标比例的理由。若没有新的重要事实或规则触发，保持原计划也是一个完整决定。

### 两类账户怎样分工

| 项目 | 自己的动态组合 | 宝宝20–30年目标账户 |
|---|---|---|
| 核心任务 | 在家庭约束内维护收益来源、风险与流动性 | 满足明确的长期用途与购买力目标 |
| 复核重点 | 持仓漂移、风险重叠、现金与交易条件 | 投入进展、目标日期、长期产品、权属与接管 |
| 宏观资料用途 | 检查原假设与压力，评估有边界的调整 | 主要作为背景，不自动跟随月度宏观交易 |
| 资金纪律 | 家庭应急金在组合外；机会现金有底线 | 教育等刚性支出不能冒充危机弹药 |
| 共同要求 | 统一家庭总账，避免重复计量；具体资产与币种需穿透 | 同左；临近用钱或发生重大变化及时复核 |

账户分工是职责安排，不表示动态组合必须频繁交易，也不表示长期账户只在危机时投入。

## 2. 需要长期保留的十二条结论

以下是本库归纳的工作原则。定义与机制可查原文/公开资料；具体执行规则需结合家庭情况确认。

1. **先管理用途，再选产品。** 净资产高不等于及时可用现金充足。
2. **收益比较必须同口径。** 时间、币种、分红、费用、税和外部资金流都要说明。
3. **股票是企业权益，ETF是工具。** 风险来自实际持仓与结构，不来自产品名字。
4. **价格低于历史高点，不等于低于价值。** 估值依赖现金、竞争、投入与风险假设。
5. **安全边际不能替代能力圈。** 先解释自己理解什么、哪些事实会推翻判断。
6. **利润、现金和可分配现金不同。** 借款、赊销、资本开支与营运资金要分别理解。
7. **好企业仍要看价格，好价格仍要看仓位。** 单个判断不能越过家庭损失约束。
8. **全球配置要穿透共同风险。** 地区多可能仍集中于科技、出口、美元或同一收入来源。
9. **债券按用途、久期、信用和币种拆分。** 能卖出不等于能按原价卖出。
10. **再平衡优先维护风险预算。** 它不是无条件提高收益的技巧，动作还要考虑成本。
11. **观察信号不自动变成交易信号。** 期货、黄金、加密、VIX等需要多种解释与证据。
12. **长期规划还要管理购买力与接管。** 时间长不能保证结果，家人能否理解与执行也重要。

基础依据：[Investor.gov配置与分散](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)、[FINRA债券](https://www.finra.org/investors/investing/investment-products/bonds)、[SEC财报入门](https://www.sec.gov/about/reports-publications/investorpubsbegfinstmtguide)。本地书籍依据与扩展推导见[主题正文](11-主题学习正文.md)、[原文学习](01-投资新手必备知识.md)和[书籍笔记](03-书籍知识点第一批.md)。这些来源不等于为本手册的具体规则或个人配置背书。

## 3. 常用资料只保留三层

### 第一层：自己的事实，比更多新闻更重要

先维护实际持仓、现金、负债、未来支出和目标日期。没有这些信息，无法把宏观观点转成可检查的组合判断。记录每项产品代码/ISIN、账户、币种、市值、底层、用途、可变现条件；对固收另外记录久期、信用与到账，对跨代资金记录用途与付款表。

家庭应急金、机会现金、下一代资金分别说明职责，汇总时只计一次。不能把债券市值与“潜在可变现金”重复相加，也不能仅按券商账户标签判断资产风险。

### 第二层：八组常用事实资料

不是八个买卖信号，也不要求每天全部查询。每次只查看与当期问题、实际暴露相关的项目。

| 资料组 | 最小入口 | 要写出的结论 |
|---|---|---|
| 美国政策与发布日历 | [FOMC](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm) | 当期正式文件说了什么，与个人讲话和市场推测分开 |
| 通胀与就业 | [CPI](https://www.bls.gov/cpi/)、[PCE](https://www.bea.gov/data/personal-consumption-expenditures-price-index)、[就业](https://www.bls.gov/news.release/empsit.toc.htm) | 变化是否持续，口径与修订是什么；不凭单月确定政策路径 |
| 美元资金结构 | [H.4.1](https://www.federalreserve.gov/releases/h41/default.htm)；WALCL、WRESBAL、RRPONTSYD、WTREGEN | 统一单位与频率，区分资产、准备金、逆回购和财政账户；不机械得出“净流动性买点” |
| 利率与汇率 | [DGS2](https://fred.stlouisfed.org/series/DGS2)、[DGS10](https://fred.stlouisfed.org/series/DGS10)、[DFII10](https://fred.stlouisfed.org/series/DFII10)，家庭支出币种汇率 | 哪种利率或币种暴露需要核查，不用一条曲线替代全部风险 |
| 市场风险补偿 | [VIXCLS](https://fred.stlouisfed.org/series/VIXCLS)、[高收益OAS](https://fred.stlouisfed.org/series/BAMLH0A0HYM2) | 风险定价是否显著变化及可能解释；不设统一自动买卖阈值 |
| 国内政策、信用与需求 | [人民银行](https://www.pbc.gov.cn/)、[中国货币网](https://www.chinamoney.com.cn/chinese/)、[国家统计局](https://www.stats.gov.cn/sj/) | 操作、DR007、LPR、社融结构与需求是否相互支持，不能只看一个总量 |
| 实际持仓披露 | 产品发行人、[EDGAR](https://www.sec.gov/edgar/search/)、[披露易](https://www.hkexnews.hk/)及对应市场原件 | 费用、指数、盈利、债务、现金或条款是否改变，是否影响原论点 |
| 账户、法律与家庭事件 | 监管与机构原文，自己的目标表 | 是否影响持有资格、支付、税务、使用日期或合法接管 |

FRED代码链接、亚太与商品、REITs、跨境和付费渠道详见[信息来源章](12-信息来源与跟踪方法.md)。该章是按需工具箱，日常不用把67个入口全扫一遍。

### 第三层：观点资料用于提出问题

机构月报与专业报道每次保留少量有差异的解释，记录作者、日期、事实依据与利益立场。随后回到原始资料核实。没有来源的截图、盘中猜测、单一价格归因和“必涨必跌”内容降低权重。

一份有用的摘要应区分：事实是什么、我如何解释、另一种解释是什么、还不知道什么。不要把抄录很多新闻标题当作完成复盘。

## 4. 一条信息怎样进入决定

### 五步核查流程

| 顺序 | 问题 | 未通过时怎么办 |
|---|---|---|
| 1. 核实事实 | 是原始文件吗，所属期、发布时间、单位、修订和适用范围清楚吗？ | 保留为待核查，不据此交易 |
| 2. 确认关联 | 影响哪个账户、产品、家庭目标或原假设？ | 不扩散成全组合判断 |
| 3. 写影响路径 | 影响盈利、估值、利率、信用、汇率、流动性还是支付通道？有哪些反方解释？ | 继续研究，不给模糊观点精确仓位 |
| 4. 检查约束 | 是否触发已写明的复核规则？现金、期限、上限与成本允许吗？ | 先解决约束；可以不行动 |
| 5. 留下记录 | 决定、金额影响、理由、失效条件与下次复核何时？ | 不把事后结果改写成原先判断 |

### 同一新闻，对两个账户可能意义不同

假设出现“长端收益率上升、股票下跌”的新情况。先核实数据与原因：可能涉及通胀、供给、期限补偿或其他因素，不能仅由这两条价格确认。

动态组合需要检查长久期、权益和资金期限是否同时承压，以及实际仓位与目标偏离。宝宝账户则先看用途和付款日期：若目标仍很远、投入计划未变，未必需要相同动作；若学费即将使用，期限与币种匹配可能比宏观观点更紧迫。

关键不在于给新闻统一定性为“利空”，而在于是否影响已确认的目标、论点与预算。没有足够证据时，记录“暂不调整，继续核查”是合理的工作结果。

## 5. 配置、研究与危机时分别用什么材料

### 配置与再平衡：先看家庭总账和政策表

操作顺序：统一持仓时点与记账币种 → 新增资金计入分母 → 核对目标比例 → 检查偏离和风险重叠 → 优先评估新资金 → 比较成本 → 执行或记录不动理由。

比例合计100%只是算术要求，不证明比例适合家庭。没有现金下限和目标说明的组合，不能靠一个再平衡计算器补全。宏观判断若要形成战术偏离，还需另外记录幅度、证据、复核与恢复条件。

### 选ETF与个股：用研究卡回答不同问题

ETF重点是指数与实际暴露、注册地与结构、费用跟踪、交易、分配与已有持仓重复。个股重点是客户、利润与现金、竞争、债务、估值区间和失效条件。无论哪条路径，都要说明它在组合中承担什么职责、替代了什么风险或新增了什么集中。

没有足够证据时，研究卡的结论可以是“待研究”或“不在能力圈”，不要求每次都得出买卖答案。新资产的加入，也应有明确作用，而不是为了增加产品数量。

### 危机：先检查生存条件，再讨论机会

家庭应急金与近期付款不作为机会预算。可讨论的机会额度受到超过底线的组合现金、目标缺口、既定风险上限和交易条件共同限制。长债、信用债和黄金均不按等额现金自动计入。

停止条件包括：现金不足、收入或必要支出恶化、论点失效、产品/通道不可可靠交易、风险预算已满。不要因为“危机弹药”这个名称而必须在下跌中买入，也不要因为有一条风险新闻就自动卖出全部风险资产。

### 一个教学案例：算出缺口，也接受不能一次补足

组合为股票50、短期高质量债25、长债10、黄金5、现金10。假设冲击为−35%、−1%、−15%、−10%、0，冲击后总额为80.25，损失19.75%。若权益目标为50%，股票目标金额为40.125，当前股票32.5，缺口7.625。

如果现金底线为8，可动用现金仅2。即使权益缺口更大，也不能据此要求立即买7.625。还需评估收入、论点、其他风险及成本；可以分阶段复核或等待新增结余。这个例子说明现金约束如何限制算术缺口，不是推荐真实配置或冲击预测。

## 6. 固定留下四份工作材料

下列是空白表单，不含真实账户、默认适宜比例或自动建议。可以复制填入本章笔记或下载文件保存；不填写账号密码、证件号码、完整密钥等敏感信息。

### A. 投资政策与家庭约束

[打开投资政策模板](../templates/01-投资政策与家庭约束.md)。相对稳定地说明：资金用途、日期、币种、应急与近期支出、目标比例、损失约束、现金底线、地区与单股上限、偏离复核、禁止工具、重大变化及接管。

优先填写它，因为其他记录需要依赖这些边界。未确认项写“待确认”，不要为了把表填满而猜比例。每次修改保留日期和原因，避免随着行情临时改口。

### B. 月度组合复盘

[打开月度复盘模板](../templates/02-月度组合复盘.md)。只保留少量重要事实和与持仓相关的变化，连同当期仓位、现金、偏离、成本、决定与未知。没有变化也可以写不调整及理由。

这份表回答“本月是否需要复核或行动”，不要求证明自己准确判断了周期阶段。市场处在何种周期可以作为假设，而不是必须填写的确定标签。

### C. 标的研究与反证

[打开研究卡模板](../templates/03-标的研究与反证.md)。每项企业或基金单独记录，事实与推断分列，估值或暴露、组合职责、费用、失效条件、资金期限与下次复核明确。适用时再做DCF或专门模型，不给所有产品强套同一公式。

研究完成的标准是能解释并承认边界，不是每项都得到高分。它尤其用于避免“宏观方向看好，所以任何相关股票都可以买”的跳步。

### D. 宝宝账户年度检查

[打开长期账户检查模板](../templates/04-宝宝账户年度检查.md)。记录分项目标、币种、日期、实际投入、购买力缺口、产品与权属变化及接管安排。年度只是常规节奏，临近付款或重大变化应提前复核。

长期计划应比较投入、目标与时间的调整，不能只提高预期回报假设来消除缺口。动态账户的机会资金不得重复充当宝宝刚性目标保障。

## 7. 一套可以持续维护的节奏

| 时间 | 只做什么 | 留下什么 |
|---|---|---|
| 初次整理 | 填家庭约束、目标、真实持仓与产品身份；列出未知 | 模板A的初稿，未确认项不编造 |
| 日常按需 | 处理重要产品、账户与家庭事件；有需要再查看市场异常 | 一条事件与影响记录，不强制每天写观点 |
| 每周可选 | 将重要原件与当时解释归档，去掉重复评论 | 少量事实、解释与待核查问题 |
| 每月 | 更新总账、现金与目标偏离，评估是否触发既定规则 | 模板B；需研究的对象进入模板C |
| 每季 | 检查行业/地区/币种重叠、持仓质量和压力结果 | 预算、压力与执行问题清单，不自动改战略比例 |
| 每年或重大变化 | 重新审查家庭用途、负债、政策、长期目标与接管 | 模板A版本更新和模板D |

这是人工工作节奏，未创建自动监控或定时提醒。时间有限时优先处理资金安全、真实持仓与家庭变化，不为了追踪宏观而放弃这些基础。

## 8. 判断一份资料是否值得继续保留

保留它需要同时能说明用途和边界：来源可追溯、口径可解释、与账户或目标相关、能改变需要核查的问题、更新成本可承受。高质量资料也可能与自己当前决策无关，可以归档而非持续关注。

一次复盘应输出清楚的“不知道”而不是凑满表格。可以暂时不知道哪个宏观解释正确，但应知道现金能否满足支出、持仓是否超出预算、产品是否发生重大变化、下一步查什么。

本套材料目前还缺的个人输入是：实际资产负债、持仓代码与账户、可用现金、未来支出、收入稳定性、目标日期、损失承受力与相关身份。填入并核实之后，才有条件讨论具体比例和产品取舍；现阶段交付的是适配框架的工作方法与证据材料。

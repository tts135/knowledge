# 我的投资总结与复盘

这里是个人学习工作区。以下框架根据用户的文字整理，属于待逐项确认的草案，不代表已经填入真实账户、目标比例或家庭参数；其余总结由用户自己填写。

## 如何写入和保存

交互页面进入本节后，顶部直接显示总结编辑区，填写后点击“保存我的总结”；无需先滚动读完本篇。每一节顶部的“写本节笔记”可直接定位到独立笔记区，章节笔记自动保存，也可手动保存。

“导出全部笔记”生成 JSON 备份，包含个人总结、章节笔记和学习进度；“导出本节 Markdown”只下载当前笔记。保存不修改项目原文，只写当前浏览器。不能保存时页面会显示提示，应立即导出备份。

## 1. 我的框架草案

多资产全球配置、周期再平衡、危机预留现金，同时做跨代长期资产规划。

- 权益承担增长任务，关注北美与亚太市场；港股通偏机会型，东南亚配置经历需要复盘。
- 固收承担不同任务，拆分短期流动性候选与中长久期对冲，不能笼统视为现金。
- 宏观与衍生品价格用于观察；观察不要求持仓，也不直接生成调仓信号。
- 危机现金与家庭应急金分开，只有超过现金底线的部分才考虑用于机会加仓。
- REITs 仍处于研究阶段；下一代资金需要单列目的、日期、币种与管理安排。

以上是对用户描述的整理，不是经核实的当前持仓。具体比例、允许偏离、现金下限与执行日期仍待填写。

## 2. 我的学习结论

用自己的话解释一个概念：它解决什么问题？适用于什么情况？最容易被怎样误用？

建议格式：结论 → 原因与证据 → 适用边界 → 反例 → 对自己的影响。

## 3. 我的待验证判断

把“我相信”和“我已经核实”分开。每项记录判断日期、证据来源、反方证据、失效条件与下一次复核日期。

例如，“某类债券可充当危机资金”仍需核查实际品种的久期、信用、币种、价差与到账安排；不能仅靠名称确认。

## 4. 我的投资政策

待填写：记账币种、资金用途、应急金、目标比例、地区和行业上限、单股上限、再平衡偏离带、最低现金、战术额度、禁止事项、年度复核日及合法接管安排。

先记录约束与未知，再确定比例；不直接把教学示例复制成个人政策。

## 5. 我的错误与复盘

保留原始判断，不事后改写：当时知道什么、实际发生什么、差异来自选择/估值/仓位/汇率/费用/执行/行为中的哪一项、以后修改哪条规则。

结果好坏与决策质量分开评估。不要因为一次获利放松证据，也不要因为一次失利就推翻全部长期框架。

## 6. 下一步行动

每次只定少量能完成的学习或核查任务，写清材料、完成条件与复核时间。未确认的参数继续保留为未知，不用猜测填满表格。

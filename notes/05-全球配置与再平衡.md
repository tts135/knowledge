# 全球多资产配置与周期再平衡

更新：2026-10-20。用户提出的目标是“多资产全球配置 + 周期再平衡 + 危机预留现金 + 跨代长期规划”。以下将其整理为可检查的规则候选；用户描述的持仓经验不等于经核实的账户数据。没有实际持仓、收入负债、目标日期和风险承受力，不能据此确定个人适宜比例或推荐具体证券。

## 1. 对框架的判断

【框架解读】框架的价值在于同时考虑收益来源、风险分散与资金用途。落地时以长期战略比例为锚，用预先约定的偏离带再平衡；周期观察只支持有限幅度的调整，不替代长期配置。现金承担支付和选择权功能，不保证抄到底。

需要修正三点：债券对冲具有条件，全球股票存在共同风险因子，危机不一定使每项资产同时下跌。应在压力测试中假设多项同时受损，而非把“普跌”当作每次危机的固定规律。S01 提供配置基础，S04 说明股债相关性会改变；两者均不保证未来回报。

## 2. 先按资金用途分账，再按产品分仓

| 资金层 | 任务 | 管理方式 |
|---|---|---|
| 家庭应急与近期刚性支出 | 保生活、还债、已承诺开支 | 在可投资组合之外单列，匹配支出币种与日期；不用于危机加仓 |
| 长期核心组合 | 承担家庭长期目标 | 设长期目标比例、容许偏离、流动性与成本约束 |
| 危机机会现金 | 在承受范围内增加风险敞口 | 在核心组合总额内单列，定义最低现金、可动用部分与恢复规则 |
| 下一代目标账户 | 教育、成年启动、长期传承 | 可单独记账，但汇总风险时计入家庭总账，避免重复统计 |

现金下限由收入稳定性、支出承诺和提款需求决定；不是为了让某个回测好看。交互页的“组合最低现金”不包含外部家庭应急金。

## 3. 各类资产分工与限制

| 资产 / 观察端 | 在本框架的任务 | 必须核对的条件 |
|---|---|---|
| A 指期货、商品、黄金、加密观察 | 形成宏观假设和风险观察记录 | “A 指”具体指数和合约待确认；期货看交割月、换月和基差。观察不要求持仓，价格不是单一宏观变量的纯信号 |
| 北美股票 / ETF | 权益增长来源之一 | 行业、前十大持仓、估值、费用、基金注册地、税与交易通道 |
| 台股、日韩 ETF | 区域权益暴露 | 与美股的半导体、出口、美元需求等重叠；地区数量不等于因子分散 |
| 港股通机会仓 | 在能力圈和价格纪律内承担区域风险 | 企业基本面、流动性、准入、汇兑与政策风险；谨慎不是无限等待“最低点” |
| 东南亚 | 按预期收益与风险重新评估 | 过去不佳的个人收益是复盘材料，先区分择时、费用、汇率与市场本身，再决定权重 |
| 短久期高质量债 / 现金管理工具 | 流动性缓冲候选 | 仍核对信用、久期、赎回、价差、到账及币种；债基不是银行存款 |
| 中长久期高质量债 | 利率与衰退风险对冲候选 | 通胀或利率上升可使其下跌；不能计为等额危机现金 |
| 信用债 / 高收益债 | 信用风险收益来源 | 危机中利差可能走阔，与权益共同受损；不能冒充防守现金 |
| 黄金 | 不同风险因子的配置候选 | 无经营现金流、受实际利率等多因素影响，流动性紧张时也会跌 |
| REITs（待研究） | 不动产经营与融资风险敞口 | 上市与非上市、物业类型、负债、租约、分配来源、估值和赎回；不是高息债替代品 |
| 加密资产（若未来持有） | 独立高风险卫星仓 | 不当现金、核心防守或保证避险工具；观察仓与投资仓分开 |

## 4. 债券为什么不能笼统称为“增强版余额宝”

【公开资料 S02、S03、S06 + 通识】能卖出不等于能按原价卖出。久期越长，价格对利率越敏感；信用风险和成交深度也会改变可变现价值。IAS 7 对现金等价物强调短期、高流动性、可转换为已知金额且价值变动风险很小，这不覆盖所有债券。

【通识】利率小幅变动时，价格变化近似为“−修正久期 × 收益率变化”，忽略凸性和其他因素。例如修正久期 7、收益率上升 1 个百分点，价格约跌 7%，还未计票息、信用利差与汇率。这只是敏感度示例。

【框架解读】把每笔固收注明：目的、币种、修正久期、信用质量、到期或赎回日期、压力折价、实际到账天数。只有满足应急使用条件的部分，才计入可动用现金候选；不要与债券市值双重相加。

## 5. 风险因子与币种穿透

将股票、债券与现金都换算为家庭统一记账币种，同时保留未来支出的原币种。未对冲外币资产的本币回报 = (1 + 资产原币回报) × (1 + 汇率回报) − 1；“汇率回报”指一单位外币可兑换本币数量的变化。ETF 交易币种、基金注册地和底层货币风险是三个不同问题。

研究表至少增加行业、前十大持仓、利率久期、信用、外汇、流动性与托管机构。工资、创业收入和房产也可能与某个市场共同下跌。压力测试同时考虑家庭收入中断，而非只看金融账户。

## 6. 再平衡：先定规则，再看行情

【公开资料 S01 + 框架解读】可以定期复核，也可以使用偏离阈值。交互页仅演示“绝对百分点偏离”，例如目标 40%、实际 46% 是偏离 6 个百分点，不是 6%。示例阈值 5 个百分点不是研究得出的最优值。

候选流程：
1. 每季度复核资金用途、风险和仓位；每年审查长期目标。频率只是待用户选定的规则候选。
2. 优先使用新增资金与分红补低配资产，减少不必要的出售、税费和换汇。
3. 若达到预定偏离带，先核对风险预算与现金下限，再比较部分调整与完全回目标的成本。
4. 每次记录目标、触发原因、执行成本和调整后权重。阈值触发检查，不产生自动交易指令。
5. 长期目标只有在家庭负债、目标、承受力或长期前提改变时重新评审；不能在每次下跌后随意降低目标以逃避规则。

两种动作要分开：再平衡是恢复风险预算；战术择时是主动改变预算。后者须单列偏离上限、依据、复核期与退出条件；没有证据时可以不做。

## 7. 宏观观察：从信号到假设，再到验证

| 观察 | 可能解释 | 需要交叉核对 | 允许触发的动作 |
|---|---|---|---|
| 商品上涨 | 需求增强、供给冲击或持仓因素 | 通胀、库存、实际需求、期限结构 | 更新情景，不直接加权益 |
| 黄金上涨 | 实际利率、汇率、避险或其他需求变化 | 利率、美元、黄金自身供需 | 检查已有暴露和偏离 |
| 加密急涨跌 | 杠杆清算、风险偏好或市场特有事件 | 其他资产、资金市场和交易平台情况 | 观察记录，不推导全仓风险开关 |
| 股指期货异动 | 预期、套保、基差或流动性 | 现货、成交、时区、合约换月 | 复核信息，不机械追随 |

这些解释是候选假设，不是有胜率估计的交易模型。若不能清楚写出信号定义、滞后、失效与成本，就不据其改变战略比例。

## 8. 危机现金：先保证生存，再讨论机会

可动用机会资金 = max(0，可用组合现金 − 组合现金下限)。应急金在组合外，不参与此公式。外币现金还需满足换汇、账户通道和到账条件；高收益现金产品可能包含额外信用或流动性风险。

【框架解读】候选执行纪律：先检查现金下限和收入状况；再核对权益是否低于目标、基本面与可交易性；最后按事先约定的批次投入。可以将可用额度分成若干批，但批次数量不是优化结果，不因一次下跌耗尽全部余量。

停止加仓条件：现金低于底线、家庭收入或近期支出恶化、产品无法可靠交易、投资论点失效、目标风险预算已满。后续用新增结余、分红或上限触发的再平衡恢复现金，不能靠借款补足。

现金的成本是机会成本与通胀侵蚀；持有现金不能保证得到更好的买点。若长期等待危机，反而可能偏离长期目标，应定期复核现金目标和保留理由。

## 9. 压力情景与工具边界

至少检验增长下行、通胀上行、美元流动性紧缩，以及个人收入中断。交互页采用人为设定的一次性价格冲击，同时显示股债下跌的可能后果；不是历史回测、相关性估计、最大损失或 VaR。

净值影响近似为各资产当前权重 × 各自冲击的加总。它不含税费、汇率二次影响、强制平仓、交易暂停或持续多期演化；若冲击已使用家庭记账币种回报，就不要重复计入汇率。

## 10. 写成投资政策声明（IPS）

填写：记账币种；家庭应急金；近期支出；各目标日期；可承受金额损失；战略目标比例；各地区与行业上限；偏离带；最低组合现金；战术额度；单股上限；不使用的工具；复核日；授权与接管人。交互工具仅帮助算术检查，尚未填好的 IPS 不应被一组示例比例替代。

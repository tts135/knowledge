# 信息来源与跟踪方法：去哪里查、查什么、怎样使用

核查日期：2026-10-21。本章依据用户提供的资讯清单整理，并核对官方与机构公开入口。链接是查询入口，不是已接入的实时行情；页面不会自动抓取、定时监控或发出交易提醒。交互文档中的外部链接在新标签页打开，方便保留本章与笔记。公开阅读、数据下载、实时行情和再分发的权限可能不同，以来源当期说明为准。

适配框架：自己的动态组合服务全球多资产目标与风险预算；宝宝20–30年账户服务长期用途与购买力；期货、商品、黄金与加密价格主要作为观察对象；港股通属于用户拟定的机会型研究范围，REITs仍在学习。这里不把框架草案当成已经核实的账户事实，也不从单个指标推导具体仓位。

## 1. 先建立信息使用规则

### 四类信息分别解决什么问题

| 信息层 | 主要问题 | 应产出的记录 |
|---|---|---|
| 宏观流动性与风险偏好 | 当前风险假设是否需要复核？ | 观察、至少两种解释、交叉证据 |
| 大类资产与持仓资料 | 实际持有的产品或企业发生了什么？ | 产品条款、盈利/现金、估值和暴露变化 |
| 结构性市场与政策风险 | 是否影响支付、交易、持有或接管？ | 适用范围、生效日、受影响账户及应对核查 |
| 跨代账户低频信息 | 目标、长期工具与传承安排是否仍适用？ | 目标缺口、成本、集中度、权属与接管更新 |

资讯的作用是改进判断，而非给每天的交易找理由。保留“事实 → 解释 → 核查 → 风险预算内的决定”这条链；即使不行动，也记录为什么暂不改变原规则。

### 对原清单的几处修订

- 通胀是政策判断的重要输入，但不是独自“决定”加降息的开关；就业、金融条件、风险与政策框架也需一起读。
- 银行在美联储的准备金余额，不叫“美债超额准备金”。本章使用 `WRESBAL`，并与美债收益率、财政部一般账户分开。
- 收益率曲线倒挂、VIX或信用利差是风险线索，不能准确报出危机时间，也不直接决定现金比例。
- 黄金的实际利率关系可用于提出假设，但不是唯一、不变的定价锚；供需、央行需求、汇率等仍可能重要。
- 日本央行在2024年3月退出原有YCC及负利率框架，应跟踪当前会议文件，而不是把YCC写成始终有效的现行制度。[历史制度变更](https://www.boj.or.jp/en/mopo/mpmdeci/state_2024/k240319a.htm)与[会议入口](https://www.boj.or.jp/en/mopo/mpmsche_minu/index.htm)分别保留。
- 互联互通披露在2024年调整，不能沿用旧版“实时北向净流入”习惯；南向、北向和全部境外投资者资金也不是一回事。[调整说明](https://www.hkex.com.hk/News/Market-Communications/2024/2404122news?sc_lang=en)、[持股披露通知](https://www.hkex.com.hk/-/media/HKEX-Market/Services/Circulars-and-Notices/Participant-and-Members-Circulars/HKSCC/2024/ce_HKSCC_NOM_096_2024.pdf)。具体字段以当期页面及后续公告为准。
- “港股流动性永远大于企业盈利”“只有极端低估才能出手”“发生风险新闻就先卖出”都不在本库固化为普遍规则。短期交易条件与长期现金价值应同时研究，实际动作仍受自己的目标、证据与现金底线约束。
- 宝宝账户低频审视不等于只等危机投入：持续投入、目标期限与既定再平衡也可构成计划；何时需要改变由家庭目标和规则解释。

## 2. 从哪些免费入口开始

先收藏下表，不必一次订阅几十个平台。它们组成原始资料优先的起步集合，而不是要求每天全部打开。

| 入口 | 具体用途 | 建议使用时机 |
|---|---|---|
| [美联储FOMC日历](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm) | 找会议日期、声明、纪要与相应预测材料 | 会议前确认日历，发布后读原文 |
| [BLS CPI](https://www.bls.gov/cpi/) / [就业报告](https://www.bls.gov/news.release/empsit.toc.htm) / [BEA PCE](https://www.bea.gov/data/personal-consumption-expenditures-price-index) | 通胀与就业原始发布 | 每次月度发布后，不追每分钟解读 |
| [FRED](https://fred.stlouisfed.org/) | 按下文代码查时间序列、单位、来源和历史 | 周度复核趋势或月度记录 |
| [中国人民银行](https://www.pbc.gov.cn/) | 政策公告、社融、金融统计与货币政策报告 | 数据发布、政策变化、季度报告 |
| [中国货币网](https://www.chinamoney.com.cn/chinese/) | DR、Shibor、LPR、汇率和债券相关基准入口 | 资金面复核，先确认具体口径 |
| [国家统计局数据](https://www.stats.gov.cn/sj/) | 国内CPI、PMI、生产、消费和发布日历 | 对照国内信用与需求变化 |
| [SEC EDGAR](https://www.sec.gov/edgar/search/) / [港交所披露易](https://www.hkexnews.hk/) | 公司、基金与持仓相关正式文件 | 财报、产品变化、回购分红等事件 |
| [日本央行会议](https://www.boj.or.jp/en/mopo/mpmsche_minu/index.htm) / [台湾公开资讯观测站](https://mops.twse.com.tw/) | 亚太政策与企业披露 | 持有相关资产时按事件跟踪 |
| [上交所REITs](https://www.sse.com.cn/reits/home/) | 招募与运营披露、规则和学习材料 | 研究阶段按产品逐项阅读 |
| [美联储金融稳定报告](https://www.federalreserve.gov/publications/financial-stability-report.htm) | 系统脆弱性分析 | 报告发布与季度风险复核 |

“免费起步”主要指可公开浏览的原文与图表；部分网站需JavaScript、存在地区访问或下载限制，实时与批量数据可能另行授权。资料失效时先从对应机构首页按标题或代码找，不把搜索引擎摘要当作完整原件。

## 3. 宏观流动性主线：去哪里查、怎样读

### 美联储政策、通胀与就业

| 项目 | 原始入口与查询方法 | 更新/跟踪节奏 | 阅读时保留的边界 |
|---|---|---|---|
| FOMC声明、纪要、经济预测 | [会议日历](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm)，选择会议对应Statement、Minutes和发布的预测附件 | 按会议与文件日历；不是每次会议都有新点阵图 | 预测是当时条件下的判断，不是未来利率承诺；区分决议、官员个人观点与媒体推断 |
| CPI | [BLS CPI](https://www.bls.gov/cpi/)，进入发布稿和表格 | 月度发布后 | 同比、环比、核心/整体、季调/非季调分开；不能拿单月噪声证明趋势 |
| PCE价格 | [BEA PCE](https://www.bea.gov/data/personal-consumption-expenditures-price-index)，查看Current Release及表格 | 月度发布，修订也记录 | 不与CPI混为一套口径；整体和核心分开 |
| 非农与失业率 | [BLS Employment Situation](https://www.bls.gov/news.release/empsit.toc.htm) | 月度发布，注意修订 | 非农与失业率来自不同调查；就业量、参与率、工资与历史修订交叉阅读 |
| 发债与融资安排 | [美国财政部季度再融资](https://home.treasury.gov/policy-issues/financing-the-government/quarterly-refunding) | 季度文件与有关公告 | 发行规模、期限结构、市场吸收与利率影响不是单向确定关系 |

北京时间使用者应查看来源公布的时区，再换算日程；美国夏令时变化会改变与北京的时差，不把全年发布固定成一个北京时间。避免把“数据所属月份”“发布时间”和“你读到新闻的时间”混为同一日期。

### 准备金、资产负债表、逆回购和财政账户

| 想查的量 | 一手/序列入口 | 口径与使用方式 |
|---|---|---|
| 美联储总资产 | [H.4.1原始发布](https://www.federalreserve.gov/releases/h41/default.htm)，[FRED WALCL](https://fred.stlouisfed.org/series/WALCL) | 周度、周三时点序列；说明资产负债表的一部分，不等于全部可投资风险资产资金 |
| 存款机构准备金余额 | [FRED WRESBAL](https://fred.stlouisfed.org/series/WRESBAL)；来源回溯H.4.1 | 周平均口径；是银行体系在美联储的准备金，不是美债余额或所有银行可随意拿去买股票的钱 |
| ON RRP操作规模 | [纽约联储逆回购操作](https://www.newyorkfed.org/markets/desk-operations/reverse-repo)，[FRED RRPONTSYD](https://fred.stlouisfed.org/series/RRPONTSYD) | 日度操作数据；同时看工具条件、货币基金等参与者的资金选择 |
| 财政部一般账户TGA | [FRED WTREGEN](https://fred.stlouisfed.org/series/WTREGEN) | 周平均序列；与财政现金收支及银行体系变化结合，不能把财政账户等同市场风险偏好 |

这里最常见的错误是把几个图的数直接相减。`WALCL`是周三时点，`WRESBAL`和`WTREGEN`为周平均；`RRPONTSYD`为日度。各页还可能使用百万或十亿美元不同单位。即使统一日期与单位，“总资产−TGA−RRP”等简化指标也不是监管机构定义的完整流动性，更不能直接推出股市应涨多少。

### 利率、美元与风险偏好：可直接收藏的代码

| 指标 | 入口 | 核心含义与误用 |
|---|---|---|
| 2年期美债收益率 | [DGS2](https://fred.stlouisfed.org/series/DGS2) | 利率条件观察之一，不是纯粹的政策预测 |
| 10年期美债收益率 | [DGS10](https://fred.stlouisfed.org/series/DGS10) | 结合期限、通胀、供给及风险补偿研究；收益率上涨不等于经济一定变好 |
| 10年减2年利差 | [T10Y2Y](https://fred.stlouisfed.org/series/T10Y2Y) | 固定使用10Y−2Y方向；负值是该口径倒挂，不是精确衰退倒计时 |
| 10年TIPS实际收益率 | [DFII10](https://fred.stlouisfed.org/series/DFII10) | 与实际折现环境相关，不等于“名义收益率减当前CPI”；不单独决定黄金 |
| VIX | [Cboe说明与数据入口](https://www.cboe.com/tradable_products/vix/)，[FRED VIXCLS](https://fred.stlouisfed.org/series/VIXCLS) | 从期权价格反映的预期波动；FRED此序列是日收盘，不是实时值，也不是下跌方向或资金流指标 |
| 美国高收益债OAS | [BAMLH0A0HYM2](https://fred.stlouisfed.org/series/BAMLH0A0HYM2) | 信用风险补偿的观察量；不是违约率。百分数与基点应换算清楚：1个百分点=100基点 |
| 美元指数DXY/USDX | [ICE合约与指数入口](https://www.ice.com/products/194/US-Dollar-Index-Futures) | 确认看的究竟是现货指数还是期货合约，以及报价时间和授权 |
| 广义贸易加权美元 | [DTWEXBGS](https://fred.stlouisfed.org/series/DTWEXBGS) | 可公开查询的美元观察补充；篮子与方法不同，不能把它改名成DXY或拼接两者历史 |
| 黄金价格、ETF持有与需求 | [世界黄金协会Goldhub](https://www.gold.org/goldhub/data) | 先标明现货/期货、币种、频率；协会也有行业立场，部分数据权限另看说明 |

公开时间序列可能滞后，也可能因假期缺值。FRED页面提供来源、单位和频率，不代表其中所有数据由美联储自行采集，第三方序列的版权与授权仍需阅读。

### 国内政策、信用与汇率

| 要查什么 | 在哪里、用什么关键词 | 怎样与自己的组合连接 |
|---|---|---|
| 公开市场操作与政策工具 | [人民银行](https://www.pbc.gov.cn/)查“公开市场业务交易公告”“7天期逆回购”“MLF”“货币政策执行报告” | 区分操作利率、规模、到期和净投放；不要只看MLF就判断全部政策。政策工具框架以当期官方文件为准 |
| LPR | [中国货币网LPR专页](https://www.chinamoney.com.cn/chinese/bklpr/) | 贷款定价参考与资金市场利率不同，不能把LPR、DR007和Shibor当同一数值 |
| DR007、Shibor、债券收益率曲线 | [中国货币网](https://www.chinamoney.com.cn/chinese/)的本币市场、行情与基准栏目 | 选择DR007成交加权口径并保留日期；[回购定盘利率说明](https://www.chinamoney.com.cn/chinese/bkfrr/)里的FDR007与DR007不是同一个完整口径 |
| 社融、M2、人民币信贷 | [人民银行](https://www.pbc.gov.cn/)查“社会融资规模增量”“存量”“金融统计数据报告” | 区分存量增速与新增量、同比与基数、政府债和私人信用构成；M2增长不直接等于股市新增资金 |
| 需求、价格与生产 | [国家统计局](https://www.stats.gov.cn/sj/)查CPI、PMI、工业、消费、房地产及发布日历 | 信用与实际需求交叉检验，不把一个总量覆盖所有行业 |
| 人民币汇率与跨境规则 | [中国货币网](https://www.chinamoney.com.cn/chinese/)与[外汇局](https://www.safe.gov.cn/) | 区分中间价、在岸CNY、离岸CNH、交易价格；规则变化看原文适用范围，不从某个汇价推断资本管制 |

## 4. 各资产对应的资料入口

### 权益与基金：宏观之外，持仓本身必须研究

| 对象 | 优先资料 | 跟踪重点与频率 |
|---|---|---|
| 美股ETF及其底层公司 | [SEC EDGAR](https://www.sec.gov/edgar/search/)按公司/基金名称、代码或CIK查文件；基金发行人的官方产品页 | 基金指数、持仓、费用、跟踪差异、分配和重要条款；企业10-K、10-Q及事件披露。基金按月/季与事件复核，财报按披露周期 |
| 美国财政与利率背景 | [财政部季度再融资](https://home.treasury.gov/policy-issues/financing-the-government/quarterly-refunding) | 发行期限和供给作为背景，不能代替公司盈利与基金结构 |
| 日本ETF | [日本央行会议](https://www.boj.or.jp/en/mopo/mpmsche_minu/index.htm)、基金官方页；[日本经济产业省](https://www.meti.go.jp/english/)的Statistics → Indices of Industrial Production | 当前政策、日元与实际行业暴露；生产数据按月。METI本次自动读取受403限制，可用普通浏览器或从首页导航 |
| 韩国ETF | [韩国银行ECOS](https://ecos.bok.or.kr/)与[韩国海关](https://www.customs.go.kr/english/main.do)的News/Trade Statistics | 先区分政策、全月出口、月内阶段性数据、半导体构成与基数。ECOS为动态页面，需要浏览器；不假设所有数据实时可导出 |
| 台股与半导体 | [公开资讯观测站MOPS](https://mops.twse.com.tw/)、[台积电月营收入口](https://investor.tsmc.com/english/monthly-revenue)、[台湾经济主管部门统计](https://www.moea.gov.tw/Mns/dos_e/home/Home.aspx)、[财政统计入口](https://www.mof.gov.tw/Eng/) | 公司披露、月营收、出口订单与实际出口分开；月营收不等于季度利润。台积电页面本次抓取超时，可由MOPS或公司IR导航交叉定位 |
| 港股通机会研究 | [披露易](https://www.hkexnews.hk/)、[港交所数据目录](https://data.hkex.com.hk/)、[金管局统计](https://www.hkma.gov.hk/eng/data-publications-and-research/data-and-statistics/) | 回购、分红、盈利、负债、交易深度与港币资金条件；按事件及月/季复核。南向交易只是部分参与者，不代表全部外资进出 |
| 东南亚低权重观察 | 持有基金官方页、当地央行/交易所/统计机构；低频背景可看[世界银行经济展望](https://www.worldbank.org/en/publication/global-economic-prospects) | 按实际暴露复核，降低关注频率不等于只看过去收益；如仍持有，产品重要事件不能遗漏 |

查询基金时先写下产品代码、ISIN、注册地、上市地与官方链接。代码可能在不同市场重复，不能把不同份额或不同法律载体的数据拼成同一只基金。基金发行人尚未由用户提供，因此本章不给不存在的“你的ETF”文件链接，也不为补清单而推荐购买具体产品。

港股“机会仓”是用户拟定的职责，不是对所有投资者的仓位建议。低估分位依赖指数、盈利、样本期与估值方法；流动性悲观与企业价值恶化可能同时发生，不能只用低分位代替商业判断。

### 固收、期货、商品和加密观察

| 对象 | 来源 | 具体查什么，避免什么 |
|---|---|---|
| 国内债券及债基 | [中国货币网](https://www.chinamoney.com.cn/chinese/)、基金官方披露及对应发行文件 | 期限/久期、信用、赎回、流动性、受限资产和收益率曲线。债基净值平稳不等于可按原价赎回 |
| 城投等信用事件、理财产品 | 对应发行人/产品管理人正式公告、合同、交易场所与监管公告 | 事件是否真的影响自己的持仓、担保与偿付；不把社交媒体传闻当违约确认，也不默认信用支持 |
| 海外债与信用压力 | DGS2/DGS10、[高收益OAS](https://fred.stlouisfed.org/series/BAMLH0A0HYM2)、[财政部融资文件](https://home.treasury.gov/policy-issues/financing-the-government/quarterly-refunding)、发行人文件 | 基准利率、信用利差和流动性分开；不能把利差当实际违约率 |
| “A指”期货 | 若指A50，先看[SGX A50合约入口](https://www.sgx.com/derivatives/products/ftse-china-a50-index-futures)；若指境内股指，查[中金所](https://www.cffex.com.cn/) | 先确认具体指数、交易所、合约月、时区和对应现货；基差含持有成本等因素，不是纯情绪。SGX为动态页，中金所本次读取超时；未确认前不混用两类合约 |
| 原油 | [EIA短期能源展望](https://www.eia.gov/outlooks/steo/)及相应交易所合约资料 | 库存、供需、期限结构与地区品种；油价上涨既可能是需求，也可能是供给冲击 |
| 铜与金属 | [CME铜](https://www.cmegroup.com/markets/metals/base/copper.html)、[上期所](https://www.shfe.com.cn/)产品与数据栏目 | 合约单位、交割月、库存、价差与品种差异；“铜博士”不是制造业的单一无误预测器 |
| 持仓分类 | [CFTC COT](https://www.cftc.gov/MarketReports/CommitmentsofTraders/index.htm) | 报告日期、持仓所属日、分类与市场；有发布滞后，不把分类持仓推成全部“聪明钱”动向 |
| 黄金 | [Goldhub数据](https://www.gold.org/goldhub/data)与[DFII10](https://fred.stlouisfed.org/series/DFII10) | 同时保留价格、币种、实际收益率和需求解释；价格上涨本身不产生买入信号 |
| BTC/ETH、USDT及平台资金 | 先记录所用交易平台官方行情/状态页、交易对、报价时点；[Tether披露](https://tether.to/en/transparency/)仅作发行方资料 | 不同平台/交易对不可直接拼接；溢价可能包含本地支付、渠道和平台风险，链上流量也依赖地址标注。发行方披露不是独立安全保证，更不等于美元银行存款 |

加密平台尚未由用户指定，本章不推荐交易平台注册、不代开户，也不以USDT溢价计算“全球美元流动性”。若资料不可复核，就把它留在辅助观察或未知栏，而不是强行得到结论。

### REITs研究阶段的原始文件

优先从[上交所REITs专栏](https://www.sse.com.cn/reits/home/)及其[定期报告入口](https://www.sse.com.cn/reits/announcements/periodic/)进入具体产品，再看管理人官网；深市产品从[深交所](https://www.szse.cn/)的公募REITs/基金披露栏目定位。本次深交所抓取超时，不能据此保证某个深层链接始终可用。

阅读顺序：招募说明书 → 底层项目与收费机制 → 运营报告 → 财务与可供分配金额 → 债务、资本开支、扩募和重大事项。出租型资产关注空置、续租和客户集中；非出租型资产则按实际收费与运营指标分析，不能给所有项目统一填“空置率”。

海外REITs从发行人IR及对应市场正式披露开始，美国证券可用EDGAR。分配率不等于总回报，资金成本之外还要看底层经营与必要投入；上市与非上市结构的退出条件也不同。研究资料齐全不代表已经适合纳入自己的组合。

## 5. 结构性市场与政策风险：先确认影响路径

| 风险类 | 原始入口 | 核查重点 |
|---|---|---|
| 银行与金融体系脆弱性 | [美联储金融稳定报告](https://www.federalreserve.gov/publications/financial-stability-report.htm)、[IMF GFSR](https://www.imf.org/en/Publications/GFSR)、[BIS统计](https://www.bis.org/statistics/)；具体事件再读监管、机构与交易场所公告 | 总体风险与特定机构状况区分；报告存在频率与时滞，不是危机预告器 |
| 制裁、贸易与资本限制 | [美国OFAC](https://ofac.treasury.gov/)、[中国商务部](https://www.mofcom.gov.cn/)、[外汇局](https://www.safe.gov.cn/)及对应司法辖区的原始法律文件 | 是提案、正式规则还是已生效措施？适用谁、何时生效、是否影响自己的产品和账户？ |
| 主权融资与债务安排 | [美国财政部季度再融资](https://home.treasury.gov/policy-issues/financing-the-government/quarterly-refunding)、有关财政/债务机构正式文件 | 预算赤字、发行、债务上限与实际违约不是同一事件，不能只读一个“债务危机”标题 |
| 交易与跨境通道 | 交易所、券商/托管人与监管正式通知；互联互通看[港交所市场通讯](https://www.hkex.com.hk/News/Market-Communications?Category=Mutual+Market&sc_lang=en&view=CardView) | 交易暂停、额度、产品资格、结算、转账和实际到账；保留账户层面确认 |

遇到重大新闻，先核实事实和自己的暴露，再检查必要支付、现金底线、可交易性和目标预算。确需调整时记录依据与执行限制。不要把“先提高现金”写成所有系统新闻的自动应对；恐慌出售本身也可能产生损失和成本。

## 6. 宝宝长期账户：低频观察的重点

| 跟踪项 | 获取位置 | 应用于哪类决定 |
|---|---|---|
| 人口与长期经济背景 | [联合国人口展望](https://population.un.org/wpp/)、[世界银行经济展望](https://www.worldbank.org/en/publication/global-economic-prospects)、国家统计机构 | 形成长期情景，不从某条人口曲线直接推断股票回报；预测要保留版本与假设 |
| 长期工具是否仍符合目标 | 持有基金官方产品页、招募及年度文件；美国基金也可查[EDGAR](https://www.sec.gov/edgar/search/) | 费用、跟踪、指数变化、集中度、注册地、分配、基金清盘/合并等事件；优先于追逐AI或长寿主题故事 |
| 底层经营质量 | 对应公司IR与市场披露系统 | ROE、盈利、分配和投入要有口径；宽基不能只凭几个明星公司ROE判断整体适合长期持有 |
| 税务、继承与账户权属 | [IRS国际纳税人入口](https://www.irs.gov/individuals/international-taxpayers)、账户和基金相关司法辖区的税务机关、合格专业人员 | 身份、资产所在地、受益与接管安排变化；不用美国规则替代所有市场，也不依据未通过提案操作 |
| 家庭目标与投入能力 | 自己的目标表、支出、收入与实际投入记录 | 每年比较目标币种购买力缺口，必要时调整投入、目标或时间；不是只等大危机才执行长期计划 |

年度复核是节奏候选，不意味着一年内任何事件都可以不理。基金清盘、账户通道、税务身份、家庭用途或临近学费付款等变化需要及时处理。动态组合与跨代账户可以分账，但家庭总风险与现金需求仍须汇总且不重复计量。

## 7. 免费与付费渠道怎样取舍

### 三层渠道，而不是把媒体和原始统计混在一起

第一层是本章的央行、统计机构、监管、交易所、发行人和产品原件，确认事实。第二层是带来源的专业数据整理，帮助统一时间序列。第三层是新闻和研究观点，帮助提出解释，再回到第一层核实。

| 渠道 | 适合解决的问题 | 获取与成本边界 |
|---|---|---|
| 官方原件、FRED及本章公开入口 | 核对数据、定义、文件与历史 | 多数原文可公开阅读；动态页、下载、实时、API和再分发可能有不同限制 |
| [Wind](https://www.wind.com.cn/) / [同花顺iFinD](https://www.51ifind.com/) | 有权限时方便查询国内宏观、市场、公司与产品数据 | 商用服务按账户和模块授权，不能假定全部免费或本机已开通；先判断实际缺口，本文未查询报价或办理订阅 |
| [Reuters Markets](https://www.reuters.com/markets/) / [Bloomberg Markets](https://www.bloomberg.com/markets) | 事件线索和专业报道 | 可能受订阅、地区或访问权限限制；媒体报道与终端数据不是同一产品。Reuters本次自动读取受限 |
| [财新](https://www.caixin.com/) | 国内外经济与政策报道、研究线索 | 部分内容需订阅；财新报道、财新相关调查和官方统计要分别标注 |
| 机构宏观月报与策略报告 | 比较不同解释、检查自己的盲点 | 从机构官方研究页或合规授权渠道获取，记录作者、日期、假设与利益立场；不靠转发截图和无来源网盘 |

不需要为了完成这份清单购买终端。先用公开入口完成一轮月度记录，只有在历史下载、横向口径或产品覆盖确有缺口时，再评估已有授权或商用服务。付费不会把观点变成事实，也不能省略来源核对。

### 过滤噪音的具体办法

优先降低无来源的短线利好、单日涨跌归因、网红仓位、币圈热点和“某指标必涨必跌”的权重。降低噪音不意味着忽略自己的持仓公告：若做个股研究，盈利、治理、债务与重大风险仍必须关注。

每条信息先问：它是新事实还是重复评论？会改变哪个已写明的假设？影响的是长期现金、估值、流动性还是仅为价格变化？如果无法说出影响路径，就留在观察栏，不占用调仓预算。

## 8. 个人跟踪节奏与一页复盘模板

以下是人工复核节奏的候选安排，不是已创建的定时任务，也不强制每日查看。没有新事实时可以不调整。

| 节奏 | 动态组合 | 宝宝长期账户 |
|---|---|---|
| 日常可选，约5–10分钟 | 浏览重要公告；快速看利率、风险溢价及国内资金面是否出现需要核查的异常，不逐笔追价 | 通常无需日常宏观盯盘，保留产品与账户重要事件入口 |
| 每周约20–30分钟 | 用同口径记录趋势、重要发布、解释与待核查项，检查现金是否满足用途 | 若无重大变化，不必跟随周度报告交易 |
| 每月数据更新后 | 通胀、就业、社融与需求交叉复核；检查是否触发自己的原定规则 | 记录既定投入与重要产品变化；不自动套用动态组合的月度动作 |
| 每季度 | 汇总仓位、估值口径、行业/地区重叠、现金下限与执行成本 | 按目标需要复核风险与进展，避免把季度波动当长期论点 |
| 每年及重大变化时 | 审查IPS、家庭负债、收入、目标与账户通道 | 检查购买力缺口、目标币种、投入能力、权属与接管；临近刚性支出时提高复核频率 |

### 每周可复制记录

将下面内容复制到本章笔记，按需删减。它保留过程证据，不要求为凑表格每天写一条观点。

```text
复核周 / 记录时间（北京时间）：
适用账户：动态组合 / 宝宝账户 / 家庭整体

本周实际发布了什么？原始链接、发布日期、数据所属期：
关键数据：数值、单位、同比/环比、季调、修订前后、口径：
与上次相比的事实变化（最多三项）：
解释A / 解释B：
支持与反方证据：
影响路径：盈利 / 估值 / 利率 / 信用 / 流动性 / 通道 / 家庭支出
实际影响到哪些持仓或目标？
当前组合现金、最低现金、近期付款是否仍匹配？
是否触发原定复核规则？哪一条？
决定：不变 / 继续核查 / 在既定预算内评估调整；理由：
尚不知道什么、下一次复核何时：
```

### 怎样避免看似严谨、实际不可比的记录

保留原件和当时版本。记录最新值，也标明它属于哪天；区分月度数据与日行情、统计初值与修订值、同比与环比、现货与期货、不同基金份额。若来源只提供延迟数据，就明确延迟，不用“实时”包装。

回测或复盘时不能把后来修订的数据冒充当时已知信息；价格、预测、媒体观点也应分别存放。资源名单的作用是降低查找成本和误读，不能让不确定的周期判断变成确定的仓位答案。
